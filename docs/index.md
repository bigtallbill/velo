# Velo

Velo is a **fast, friendly non-linear video editor** for Linux, Windows and
macOS, built with C++20, Qt 6 and FFmpeg. It follows the familiar
Premiere-style layout — a project bin, media-preview and sequence monitors,
effect controls and a multi-track timeline — while staying small, hackable
and quick.

![Velo editing the showcase project](assets/screenshot.png)

## Highlights

- **Multi-track editing** — unlimited video and audio tracks, magnetic
  snapping, edge trimming, razor tool, ripple delete, linked A/V,
  copy/paste and nested sequences.
- **Organized media** — import files or whole directories; folders in the
  project bin mirror your directory structure, with thumbnails and search.
- **Keyframes everywhere** — position, scale, rotation, opacity, volume and
  every effect parameter animate with smooth-step interpolation.
- **Real audio tools** — waveforms on clips, a draggable volume line,
  per-track volume, pitch-preserving speed changes and audible scrubbing.
- **Modular effects** — color grading and correction, blur, sharpen,
  vignette and more, plus cross dissolves, fades and dip-to-black
  transitions.
- **Serious export** — H.264, H.265/HEVC, VP9, AV1 and ProRes, with NVIDIA
  hardware encoding when available, at any resolution and frame rate.
- **Portable projects** — everything saves to a single JSON `.velo` file
  with full snapshot undo/redo.
