# Keyboard shortcuts

Every action below is **rebindable** — see [Customizing](#customizing).
These are the defaults.

## File

| Shortcut | Action |
|---|---|
| ++ctrl+alt+n++ | New project |
| ++ctrl+o++ | Open project |
| ++ctrl+s++ | Save project |
| ++ctrl+shift+s++ | Save project as |
| ++ctrl+i++ | Import media files |
| ++ctrl+shift+i++ | Import a folder (recursive) |
| ++ctrl+n++ | New sequence |
| ++ctrl+m++ | Export |
| ++ctrl+q++ | Quit |

## Editing

| Shortcut | Action |
|---|---|
| ++ctrl+z++ | Undo |
| ++ctrl+shift+z++ | Redo |
| ++ctrl+c++ | Copy selected clips |
| ++ctrl+v++ | Paste at playhead |
| ++ctrl+a++ | Select all clips |
| ++s++ | Split selected clips at playhead |
| ++shift+s++ | Split all tracks at playhead |
| ++del++ | Delete (clips in the timeline; items in the bin) |
| ++alt+del++ | Ripple delete |
| ++alt+c++ | Chain selection into a nested sequence |
| ++f2++ | Rename the selected bin item |
| ++ctrl+k++ | Keyboard shortcut editor |

## Sequence & timeline

| Shortcut | Action |
|---|---|
| ++ctrl+shift+v++ | Add video track |
| ++ctrl+shift+a++ | Add audio track |
| ++t++ | Add text at playhead |
| ++equal++ | Zoom in |
| ++minus++ | Zoom out |
| ++backslash++ | Zoom to fit |
| ++n++ | Toggle magnetic snapping |
| ++v++ | Selection tool |
| ++c++ | Razor tool |

## Playback

| Shortcut | Action |
|---|---|
| ++space++ | Play / pause |
| ++left++ / ++right++ | Step one frame |
| ++shift+left++ / ++shift+right++ | Step five frames |
| ++home++ / ++end++ | Go to start / end |
| ++i++ | Set in point (Media Preview) |
| ++o++ | Set out point (Media Preview) |
| ++ctrl+shift+x++ | Clear in/out points |

## Mouse

| Gesture | Action |
|---|---|
| ++ctrl++ + wheel | Zoom the timeline at the cursor |
| Wheel | Scroll the timeline |
| Hold ++alt++ while dragging | Bypass magnetic snapping |
| Hold ++shift++ on a corner handle | Non-uniform scale in the monitor |
| Drag a numeric label | Scrub the value (++shift++ = 10×) |
| ++ctrl++ + click a volume line | Add a volume keyframe |
| Double-click a volume dot | Remove the keyframe |

## Customizing

*Edit → Keyboard Shortcuts…* (++ctrl+k++) opens the editor: click any
shortcut field and press the new combination. Changes save immediately
and persist **per user** — they are not part of the project file. Use the
field's clear button to unbind an action.
